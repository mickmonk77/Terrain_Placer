5. External Wall Facing

A wall counts as "outer" if it sits within this distance of the JSON's bounding-box edge, after placement. Increase if outer walls aren't all being caught.

6. Wall Chain Alignment

Gap/Line Tolerance control which segments count as one chain (increase Gap Tolerance if long walls aren't being detected as one run). Smoothing Window is how many neighbouring segments each one blends with — higher = gentler transitions but less exact to the raw terrain, 1 = off.

7. Slope Alignment

Smaller radius = slope taken from a tighter point (more extreme). Larger radius averages the ground under the object (gentler).
